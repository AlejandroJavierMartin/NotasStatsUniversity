# Notas Stats v5

Sistema académico para gestionar estudiantes, grupos, asignaturas y notas.

Arquitectura:
- frontend: React/Tailwind (pendiente de conectar)
- backend: FastAPI
- database: SQLite

Módulos previstos:
- Gestión de grupos
- Gestión de estudiantes
- Gestión de asignaturas
- Notas por estudiante y asignatura
- Importación PDF/DOCX/XLSX/CSV/JPG/PNG
- OCR
- Editor antes de guardar
- Exportación

Este paquete es la base inicial del proyecto v5.
